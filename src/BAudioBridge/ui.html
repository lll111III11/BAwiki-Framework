杜比预设走 ffmpeg 滤镜链：上混 = Dolby Surround 的声场展开，影院 = 上混 + 对白增强 + 低频 + 压缩，夜间 = 响度均衡 + 压缩。它们只做“效果”，不解 AC-3 的商业编码——真正的杜比码流由 ffmpeg 直接解码。
